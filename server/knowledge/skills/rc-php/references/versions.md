# PHP features by version (as of 2026-10)

Use to check "is this available on our minimum PHP?". Sources: php.net release pages and migration guides, accessed 2026-10-09.

| Version | Language / API you can use | Deprecated or removed (stop using) |
|---|---|---|
| 8.0 (EOL) | union types, `match`, nullsafe `?->`, named args, constructor promotion, attributes, `str_contains/starts_with/ends_with`, `mixed`, `static` return, JIT | PDO errmode exception by default |
| 8.1 (EOL 2025-12-31) | enums, readonly properties, first-class callable `f(...)`, `new` in initializers, pure intersection types, `never`, fibers, `array_is_list`, `#[\ReturnTypeWillChange]` | `Serializable` without `__serialize`, passing null to non-nullable internal params, `$GLOBALS` writes restricted |
| 8.2 (security to 2026-12-31) | readonly classes, DNF types `(A&B)\|null`, `true`/`null`/`false` standalone types, constants in traits, `Random\Randomizer`, `#[\SensitiveParameter]` | dynamic properties, `${}` interpolation, `utf8_encode/decode`, partially supported callables like `"self::m"` |
| 8.3 (security to 2027-12-31) | typed class constants, `#[\Override]`, `json_validate()`, dynamic class constant fetch `Foo::{$name}`, readonly props re-initializable inside `__clone`, `mb_str_pad`, `Randomizer::getBytesFromString`, `str_increment/decrement`, `-l` lints multiple files | `get_class()`/`get_parent_class()` without args, `assert_options()` |
| 8.4 (active to 2026-12-31) | property hooks, asymmetric visibility, lazy objects, `#[\Deprecated]`, `array_find/find_key/any/all`, `new Foo()->m()`, `Dom\HTMLDocument`, `BcMath\Number`, `Pdo\*` subclasses + `PDO::connect`, `mb_trim/ltrim/rtrim`, `mb_ucfirst/lcfirst`, `request_parse_body()`, `http_get_last_response_headers()`, `RoundingMode` enum, `DateTime::createFromTimestamp()`, IR JIT, bcrypt cost 12 | implicit nullable params, `E_STRICT`, `trigger_error(E_USER_ERROR)`, CSV functions without `escape`, `lcg_value()`, `mysqli_ping/kill/refresh`, `xml_set_object`, session settings that enable URL-based session IDs, `_` as class name; IMAP, OCI8, PDO_OCI, pspell unbundled to PECL |
| 8.5 (active to 2027-12-31) | pipe `\|>`, URI extension (`Uri\Rfc3986\Uri`, `Uri\WhatWg\Url`), `clone($o, [...])`, `#[\NoDiscard]` + `(void)` cast, `array_first/last`, closures/FCC in constant expressions, `#[\Override]` on properties, `#[\Deprecated]` on traits/constants, attributes on constants, final promoted props, asymmetric visibility on static props, `Closure::getCurrent()`, `get_error_handler()`, `get_exception_handler()`, `curl_share_init_persistent()`, partitioned cookies, `Dom\Element::getElementsByClassName/insertAdjacentHTML`, `grapheme_levenshtein()`, fatal-error backtraces | backticks, non-canonical casts, `case X;`, `__sleep/__wakeup` (soft), `null` array offset, non-numeric string `++`, `curl_close`, `imagedestroy`, `finfo_close`, `xml_parser_free`, `mysqli_execute`, `setAccessible()`, `$http_response_header`, `SplObjectStorage::attach/detach/contains`, `PDO` driver-specific constants/methods on base class, `report_memleaks`; `disable_classes` INI removed |
| 8.6 (RC3, GA 2026-11-19; may change) | partial function application, `clamp()`, readonly props with default values, `#[\Override]` on class constants/enum cases, `__debugInfo()` on enums, `mysqli_quote_string()`, `Uri\Rfc3986\UriBuilder`/`Uri\WhatWg\UrlBuilder`, stream error API, JSON error locations | session defaults now strict mode + HttpOnly + SameSite=Lax; deprecates `is_double/is_long/is_integer/doubleval`, `metaphone`, `spl_object_hash`, `strcoll`/`SORT_LOCALE_STRING`, mbregex, `namespace/let/is/_` as identifiers; `\f` added to default `trim` chars |

PHP 9.0: no release date or confirmed removal list found on php.net (unverified). Treat every deprecation above as a future removal.
