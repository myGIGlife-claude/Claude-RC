# Three.js, WebGL and code-made video (details for rc-ui-craft)

Distilled 2026-11-25 from MIT/Apache-2.0 skills by cloudai-x (written for three.js r186), MengTo, remotion-dev (no license file seen: read as reference only), heygen-com (Apache-2.0). Check the installed three.js version: names below change between releases.

## Three.js (WebGL)
- Loop and time: `renderer.setAnimationLoop`, `THREE.Timer` (Clock is deprecated since r183). WebGPURenderer needs `await renderer.init()`. Import maps use `three/addons/`. `PCFSoftShadowMap` is deprecated (r182): use `PCFShadowMap`. Colors and maps: color maps `SRGBColorSpace`; normal, roughness, metalness and AO maps stay linear.
- Measure with `renderer.info` after render (counters reset each render; with multi-pass frames set `autoReset=false` and reset once per frame). Transparent double-sided meshes draw twice; transmission doubles opaque draws. Merged geometry has one bounding sphere (all-or-nothing culling): keep clusters world-sized; after moving vertices on the CPU call `computeBoundingSphere()`.
- Pixel ratio capped at 2 (cost grows with its square). If you offer a "fixed 2x" mode, label auto mode honestly (auto can render 1x on ordinary screens). Renderer and composer each hold a ratio: do not set 2x on both (4x pixels). `setSize(w,h,false)` lets CSS own displayed size.
- Shadows: each shadow light adds passes (point lights up to six); freeze static maps (`autoUpdate=false`); shadow maps are small by default. Acne: adjust `normalBias` first, then a tiny negative `bias`. Point and spot intensity is candela (values in the hundreds); changing the light count recompiles every lit material, so toggle with intensity. Compile shaders ahead (`compileAsync`) to avoid a first-frame stall.
- Materials by cost: Basic, Lambert, Phong, Standard, Physical; share instances; `alphaTest` keeps cutouts in the opaque pass. Changing `transparent`, `side`, `blending`, `flatShading`, `vertexColors` or adding/removing a map needs `needsUpdate`. Lines are always 1px (use Line2 for thick). Do not fake dielectrics (wood, stone, cloth) with metalness.
- Textures: size to what is visible (texel density: a surface spanning 1200px showing half a tile suggests about a 2400px tile; do not default to 4K or 8K). A 4096 RGBA texture with mips is about 85 MB of GPU memory, a 2048 one about 22 MB. Use KTX2/Basis for GPU compression, Draco or meshopt for geometry (gltf-transform pipeline). Cap anisotropy at the device maximum, compare moderate values first. Load the first view's maps first; DOM lazy loading does not schedule WebGL textures. Cache by full asset identity and sampler settings; dispose superseded textures. Foliage cutouts: bleed edge color into transparent texels.
- Disposal: `dispose()` frees only that object; walk the subtree and free geometry, materials and textures yourself; dispose the renderer on route changes. Avoid allocations inside the frame loop; stop the loop when hidden. Reduced motion: render a still frame.
- Shaders: `ShaderMaterial` compiles as GLSL ES 3.00 (do not set `glslVersion`); end custom shaders with the tonemapping and colorspace includes or they render darker; video textures are not sRGB-decoded in a ShaderMaterial; use `renderer.debug.onShaderError` to see failed source; `onBeforeCompile` needs `customProgramCacheKey` per variant; neither runs under WebGPU (use TSL node materials).
- Post-processing order: RenderPass, linear effects, SMAA, OutputPass (tone mapping once), then FXAA. Composer buffers are not multisampled (pass your own target with samples 4). Selective bloom: null the scene background during the bloom pass.
- React Three Fiber: the Canvas owns the loop (no requestAnimationFrame inside); mutate refs in `useFrame` rather than React state; a `useFrame` priority above 0 turns off auto-render; under `frameloop="demand"` call `invalidate()` after imperative changes; R3F disposes what its JSX creates but not props, primitives or cached loader assets; drive adaptive DPR from state on the Canvas `dpr` prop. `useGLTF` loads the Draco decoder from a public CDN by default: self-host it where privacy or offline matters.
- Landing pages: one dominant WebGL lane (subtle depth field for SaaS; particles for technical; object for product; cinematic scroll for campaigns). Gates in order: headline and CTA within 3 s, DPR cap, poster first, reduced motion, contrast, context loss and resize. If conversion drops: less amplitude, more CTA contrast; if mobile stutters: fewer particles, lower DPR cap.

## Remotion
- Everything driven by the frame number; `interpolate()` over an explicit frame range (clamp unless overshoot is wanted); `Easing.bezier` or springs; keep `interpolate()` inline in style and use individual CSS transform properties (`scale`, `translate`, `rotate`) so Studio can edit them.
- `TransitionSeries.Transition` shortens the timeline by its duration (overlay does not): total = sum of sequences minus transitions; keep a scene between an overlay and a transition. Use a shared Sequence when layers must inherit trim, speed or start; independent timing props on the item otherwise.
- Audio via `@remotion/media`: trim and duration in frames, volume can be an `interpolate()` curve, no reverse playback, pitch only in server renders. If timing follows audio, measure duration first and subtract transition overlaps.
- Captions are JSON with millisecond times (not frames). Open Studio to preview; render only when asked; do not overwrite surprising edits the user made outside the chat.

## Scene seams (HyperFrames-style doctrine; adopt the ideas, not the tooling)
- Exit and entry share axis, direction and speed so the cut lands mid-motion; never mirror direction. Growing is a push, shrinking a pull; avoid shrink-exit followed by grow-from-small entry. One dominant direction per film; reserve others for meaning. Two or three inter-scene transitions per film.
- Timing: entry up to about 800 ms, exit about 75% of entry, total stagger up to about 500 ms, a 0.3 to 0.75 s stillness before the climax; no bounce or elastic easings; no idle wobble as filler. Partial travel (about 12% of frame) with mirrored power4 ease-in/ease-out; blur 10px on text-scale subjects, 18 to 20px only on full-frame surfaces, applied to the wrapper.
- A dark film can flash white at a seam: give the root an opaque canvas-colored background during opacity dips.
- Verify every seam against a written ledger (one row per cut) before calling the film done, and watch the real rendered file.
